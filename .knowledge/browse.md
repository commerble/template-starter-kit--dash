# 確認方法

ユーザが`CBPAAS_FRONT`環境変数にECサイトルートURLを登録しします。

AIエージェント等が確認する場合はこの環境変数を参照します。

確認時の運用ルール:

- `.vscode/mcp.json` の `envFile` 設定がある場合は、MCP サーバー経由で環境変数を取得する。
- MCP ツールが使えない場合、AIエージェントは別手段（ローカル `.env` 直接読取など）に自動フォールバックしない。
- MCP ツールが使えない時点で作業を停止し、ユーザへエスカレーションして実施方法の承認を得る。

サイトに基本認証を設けいている場合は、 `https://{user}:{pass}@host/path/to/the/root`のように設定します。
